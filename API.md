# API reference

Base path: `/api/v1/internships`. All bodies are JSON (`Content-Type: application/json`).

## Data model

| Field | Type | Rules |
|---|---|---|
| `id` | string | `INT-` + 3 or more digits. Generated by the server (next number); may be supplied on create |
| `title` | string | required, 3–100 chars |
| `domain` | string | required, 2–60 chars |
| `mode` | string | required: `Remote`, `Hybrid` or `On-site` (case-insensitive input, stored normalised) |
| `location` | string | required, 2–80 chars |
| `skills` | string[] | required, 1–10 unique items, 1–40 chars each |
| `openings` | integer | required, 0–1000 |
| `duration_weeks` | integer \| null | optional, 1–52 |
| `applications_open` | boolean | optional, default `true` |
| `apply_url` | string \| null | optional, `http(s)` only, no embedded credentials |
| `created_at`, `updated_at` | ISO-8601 string | read-only |

## Response format

Success (single record):

```json
{ "status": "success", "data": { "id": "INT-101", "title": "Frontend Intern", "...": "..." } }
```

Success (list):

```json
{
  "status": "success",
  "data": [ { "id": "INT-101" } ],
  "pagination": { "page": 1, "limit": 10, "total": 5, "totalPages": 1, "hasNext": false, "hasPrev": false }
}
```

Error:

```json
{
  "status": "error",
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Validation failed",
    "details": [ { "field": "title", "message": "must be at least 3 characters" } ]
  }
}
```

## Endpoints

| Method | Path | Success | Notes |
|---|---|---|---|
| GET | `/` | 200 | Query: `page`, `limit` (1–50, default 10), `q`, `domain`, `mode`, `location`, `skill`, `applications_open`, `sort` (`id`, `title`, `openings`, `created_at`; prefix `-` for descending) |
| GET | `/:id` | 200 | |
| POST | `/` | 201 | Sets `Location` header |
| PUT | `/:id` | 200 | Full replacement; all required fields needed, omitted optional fields reset to defaults |
| PATCH | `/:id` | 200 | At least one field |
| DELETE | `/:id` | 204 | No body |
| POST | `/:id/applications` | 201 | Body: `applicant_name`, `applicant_email`, optional `portfolio_url` |
| GET | `/health` (root path) | 200 | Liveness check |

## Status codes and error codes

| Status | `error.code` | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Bad body, bad query string, malformed id, unknown fields |
| 400 | `INVALID_JSON` | Body is not parseable JSON |
| 404 | `NOT_FOUND` | Unknown internship id |
| 404 | `ROUTE_NOT_FOUND` | Unknown route |
| 409 | `DUPLICATE_ID` | `POST` with an id that already exists |
| 409 | `DUPLICATE_APPLICATION` | Same email already applied to that internship |
| 409 | `APPLICATIONS_CLOSED` | `applications_open` is `false` |
| 409 | `HAS_APPLICATIONS` | Delete blocked because applications exist |
| 413 | `PAYLOAD_TOO_LARGE` | Body over 10 KB |
| 500 | `INTERNAL_ERROR` | Unexpected error (details are never leaked) |
